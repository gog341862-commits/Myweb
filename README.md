# Стюард

Браузерная игра на Three.js.

## Структура
- `index.html` — HTML-разметка, метаданные и import map.
- `css/styles.css` — стили интерфейса, HUD, диалогов, кассы и сенсорного управления.
- `js/main.js` — игровой ES-модуль: аудио, музыка, голос, сохранение, Three.js-сцена, персонажи, тележка, игровые события и интерфейс.

## Запуск
Проект использует ES-модули и import map. Запускайте через HTTP-сервер или GitHub Pages, а не через `file://`.

После публикации Pages: https://gog341862-commits.github.io/Myweb/

## Примечание
На первом этапе HTML, CSS и JavaScript разделены на отдельные файлы без переписывания игровой логики. JS оставлен одним модулем, поскольку подсистемы тесно связаны общими переменными и функциями. Дальнейшее разбиение на модули требует поэтапной проверки зависимостей и тестирования.
